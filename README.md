# ViRVIG public website runtime data

This public repository provides the JSON data, assets, and JavaScript renderers consumed by the ViRVIG GenWeb6 website.

**Do not add or edit files manually.** The private [`UPC-ViRVIG/virvig-web-docs`](https://github.com/UPC-ViRVIG/virvig-web-docs) repository is the source of truth. Its publication workflow generates and updates this repository automatically.
